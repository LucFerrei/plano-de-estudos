## Regras de ouro (uso de IA)

1. IA é tutor, não digitador — peça "explique", "revise", "me pergunte", nunca "escreva".
2. 15–30 min de luta antes de pedir ajuda.
3. Reescrever, não copiar: se a IA sugerir código, feche e digite do zero.
4. Explicar de volta: todo código aceito, você explica linha por linha.
5. Prática (katas) é 100% sem IA.
6. IA pra gerar exercícios e revisões, não respostas.

- **Backend:** SQL/Postgres até `JOIN` + transaction, pipeline de CI/CD funcional, e modelar uma fila com retry/idempotência.
- **IA:** explicar o loop agente→tool→modelo, montar `AGENTS.md`/`CLAUDE.md`, usar plano-antes-de-código, dominar permissions/MCP/subagentes e medir custo/latência.
